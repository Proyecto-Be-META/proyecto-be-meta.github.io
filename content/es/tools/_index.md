Herramientas desarrolladas en el marco del proyecto Be-META.

{{< tool name="Othimi" url="https://othimi.pro/auth" >}}
**Othimi** es la herramienta de optimización del proyecto Be-META. Permite modelar y resolver problemas de optimización aplicando técnicas metaheurísticas de forma accesible, también para usuarios sin experiencia en metaheurística o programación.
{{< /tool >}}

{{< tool name="CO-META" url="https://w3id.org/ontologies-ULL/CO-META" >}}
**CO-META** es una ontología que representa el dominio de conocimiento de las metaheurísticas, como un conjunto de componentes interconectados (generación, selección, cruce, aceptación...). La ontología incluye también los parámetros, estructuras de datos y problemas de optimización. Su objetivo es servir de herramienta que facilite la interoperabilidad de los datos de diferentes sistemas, incluyendo nuevas versiones de Othimi y la información contenida en la literatura científica; así como permitir la inferencia para comparar entre metaheurísticas.
{{< /tool >}}
