Tools developed within the Be-META project.

{{< tool name="Othimi" url="https://othimi.pro/auth" >}}
**Othimi** is the optimization tool of the Be-META project. It lets you model and solve optimization problems by applying metaheuristic techniques in an accessible way, including for users with no background in metaheuristics or programming.
{{< /tool >}}

{{< tool name="CO-META" url="https://w3id.org/ontologies-ULL/CO-META" >}}
**CO-META** is an ontology that represents the knowledge domain of metaheuristics as a set of interconnected components (generation, selection, crossover, acceptance, etc.). The ontology also encompasses parameters, data structures, and optimization problems. Its purpose is to serve as a tool that facilitates data interoperability across different systems, including new versions of Othimi and information found in scientific literature. It is also intended to enable inference to support the comparison of various metaheuristics.
{{< /tool >}}

{{< tool name="DIGNEA" url="https://github.com/DIGNEA" >}}
**DIGNEA** is a diverse instance generator based on evolutionary algorithms and Quality Diversity (QD). It is an extensible tool for generating diverse and discriminatory instances for any desired combinatorial optimisation domain. Its ultimate goal is to generate instances that are diverse and biased towards being solved easily by a specific solver selected from a predefined portfolio.
{{< /tool >}}

{{< tool name="HealthPlanify" url="https://github.com/Nestor-DF/HealthPlanify" >}}
**HealthPlanify** is an interactive web application for exploring, validating, and editing solutions to the Integrated Healthcare Timetabling Problem (IHTP) from the [IHTC 2024](https://ihtc2024.github.io/) competition. Through an intuitive interface and real-time visualisations, it enables both experts and non-technical users to analyse surgical scheduling, hospital admissions, and nurse assignments, assess associated costs, and adjust scheduling parameters interactively. The tool has been [listed](https://ihtc2024.github.io/ihtp/index.html#section4) on the official IHTC 2024 website.
{{< /tool >}}
