Tools developed within the Be-META project.

{{< tool name="Othimi" url="https://othimi.pro/auth" >}}
**Othimi** is the optimization tool of the Be-META project. It lets you model and solve optimization problems by applying metaheuristic techniques in an accessible way, including for users with no background in metaheuristics or programming.
{{< /tool >}}

{{< tool name="CO-META" url="https://w3id.org/ontologies-ULL/CO-META" >}}
**CO-META** is an ontology that represents the knowledge domain of metaheuristics as a set of interconnected components (generation, selection, crossover, acceptance, etc.). The ontology also encompasses parameters, data structures, and optimization problems. Its purpose is to serve as a tool that facilitates data interoperability across different systems, including new versions of Othimi and information found in scientific literature. It is also intended to enable inference to support the comparison of various metaheuristics.
{{< /tool >}}
